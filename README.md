# Advanced CSS3 & Responsive Architecture — Portfolio

A modern, responsive personal portfolio built with semantic HTML5, advanced CSS3, CSS Grid, Flexbox and vanilla JavaScript.

## Features

- Semantic HTML5 structure
- CSS Grid for page and project layouts
- Flexbox for navigation, buttons and component alignment
- Mobile-first responsive breakpoints for mobile, tablet and desktop
- CSS custom properties for light and dark themes
- JavaScript theme toggle with saved preference (`localStorage`)
- Responsive mobile navigation
- CSS hover transitions, transforms, gradients and shadows
- Reduced-motion accessibility support

## Run locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

No build tools or dependencies are required.

## Customize before publishing

1. Replace `Yuvan Sri` and `YS` with your preferred display name/initials.
2. Replace `your.email@example.com` in `index.html` with your email address.
3. Update the About, Skills and Projects sections with your actual details.
4. Add links to your real project repositories and live demos if available.

## Publish with GitHub Pages

1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

Your site will be available at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
